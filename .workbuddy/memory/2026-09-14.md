## 关键约定（跨会话有用）

- 本仓**没有 bun**，AGENTS.md 的 `bun run *` 用 `./node_modules/.bin/*` 等价执行。
- Bash 的 BSD grep **不支持** `a\|b` 交替，静默返回空；多模式检索用 Grep 工具（ripgrep）。
- 同一文件的多处编辑**不要并行提交**，会互相覆盖；逐条发，改完 Read 复核。
- 存储运行时缓存在 `globalThis`，`vi.resetModules()` 清不掉，测试里必须 `storage.resetStorageRuntime()`。
