# 2026-10-28

## 11128 (Illegal API invocation from an unapproved channel) — 根因结案

生产日志（Loki）里 48 小时 4193 个请求、110 个被拒（2.6%），按请求形态拆开是两件事：

| 请求形态                                         | 请求数 | 被拒 | 拒绝率 |
| ------------------------------------------------ | ------ | ---- | ------ |
| `systemPromptInjected: true`（网关补的占位提示） | 76     | 76   | 100%   |
| 调用方自带 system 提示                           | 3563   | 20   | 0.6%   |
| `toolCount 0-4`                                  | 128    | 80   | 62.5%  |
| `toolCount 130+`                                 | 3665   | 12   | 0.3%   |

结论：**外部闸门拒绝的是「占位 system 提示」这种非官方客户端签名**，不是请求头、不是 UUID 格式、不是 gzip。
占位提示 `You are a helpful assistant.` 的命中率是 100%，与 `toolCount` 高度相关只是因为裸对话请求恰好都没有 system 消息。

修法（已发版）：没有 system 消息时补官方前言（抓包得到的 16987 字原文，`lib/server/proxy/official-system-prompt.ts`），
不再补占位句子。`CODEBUDDY_INJECT_SYSTEM_PROMPT=0` 仍可关闭注入。

## 残余 0.6% 是哪来的

逐条对日志后确认：残余拒绝**集中在一个账号**上（`codebuddy_17877108187_*`：11 个请求 5 个被拒 45.5%，
其余账号 0.5%~3%）。同一个 token 连打三次 11128，说明是账号被标记，不是每次请求的随机性。

修法（已发版）：账号用完 `MAX_CHANNEL_REJECTION_RETRIES` 次重试仍被拒时，
`markCredentialLimited({ kind: 'channel', resumeAt: now + 5min })` 把它挪出轮转 5 分钟，
不再让下一个调用方再撞一次。`RateLimitKind` 增加 `'channel'` 并保证持久化后不丢。
